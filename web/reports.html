报告广场

要接一个新网关，怎么知道它靠不靠谱？用 gwbench 自己测：同一个模型，你的网关 vs OpenRouter vs 别家，一把跑完延迟 / 稳定 / 价格 / 假流式 / 偷换 / 长文本截断，出一份可分享的报告。key 不出本机。下面是公共基线报告与用户分享的报告。

自己生成一份零依赖，Node ≥ 20，key 只存环境变量

把"我的网关"和 OpenRouter、AiHubMix 放一起比 gemini-2.5-flash：

# 装好 Node，克隆仓库后：
PROBE_KEY=你网关的key OPENROUTER_API_KEY=… AIHUBMIX_API_KEY=… \
  npm run compare -- --model gemini-2.5-flash \
    --url https://my-gateway.com --name "我的网关" --with openrouter,aihubmix
# → 产出 reports/gemini-2.5-flash-<日期>.html（自包含，可直接发给别人）

想公开到这个广场？把生成的 report.json 复制进 web/reports/ 并提 PR（或用 node scripts/publish-report.mjs <report.json> 自动归档 + 更新清单）。后续会上线一键上传。
