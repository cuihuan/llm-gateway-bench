选哪个模型最值？

走哪个网关靠谱？

自测指南用你自己的 key，三分钟拨测任意一个网关 · 读懂这一维 →

榜单上没有你在用的网关？或者想亲自验一下它给的是不是真模型？把它加进 data/gateways.json，用你的 key 在本地跑同一套拨测脚本——和榜单完全一致、可复现。

# Node ≥ 20，零依赖。克隆后：
git clone https://github.com/cuihuan/llm-gateway-bench && cd llm-gateway-bench

# 最快：--url 直接拨测任意 OpenAI 兼容端点，免改文件、结果打到 stdout：
PROBE_KEY=sk-... node probe/probe.mjs --url https://your-gateway.com --model gpt-4o-mini --samples 3

# 纳入榜单+本地看板：加进 data/gateways.json 后
node probe/probe.mjs --gateway <id> --out data/results && npm run aggregate && npm run serve

它测出来的"行为指纹"

工具调用是否被剥离 · 流式真实性（假流式 = TTFT≈总延迟后一次性吐）· usage 重算（每 token 字符数异常偏低 = 疑似虚报）· TTFT/吞吐实测分位数。

为什么可信

探测 prompt、采样数、判定阈值全写在脚本里，带随机串防缓存；原始结果逐次 commit 进 data/results/，任何人可用自己的 key 复现同一结论。不做黑箱加权总分。

把你的网关加进榜单

PR 修改 data/gateways.json（填 baseUrl / authEnv / probeModels），维护者在 Secrets 配 key 后自动进入每 6 小时拨测，数据随时间积累。

方法论摘要 — 拨测：GitHub Actions 每 6h，固定 prompt 流式请求，每模型 3 采样报分位数，并发 ≤4（拨测不是压测）；cron 抖动以真实时间戳为准。政策类标注必须附证据链接与日期。

公正性 — 原始数据逐次 commit 于 data/results/，任何人可用自己的 key 复现；维护者与某网关存在利益关联时在条目中披露。
