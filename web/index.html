我们测什么

每个维度对应用户挑网关时真正会问的一个问题

① 直连性 "我能不能直接连上？"

各地域到网关的可达性与连接延迟。重点是国内直连——现有评测站都不覆盖的盲区。

② 稳定性 "它会不会半夜挂掉？"

7/30 天滚动成功率（uptime%）、错误画像（限流 / 故障 / 超时）、高峰期延迟漂移。跑得越久越有说服力。

③ 速度 "它快不快？"

流式首 token 延迟（TTFT p50/p95）与生成吞吐（tok/s），固定 prompt 多采样取分位数。

④ 价格 "它贵不贵？有没有套路？"

同一模型的网关价 ÷ 官方价 = 价格指数；并标注计费透明度（公开价格 API、缓存价、隐藏倍率）。

⑤ 模型清单 "我要的模型它有没有？"

模型数量、主流模型覆盖矩阵、协议覆盖（OpenAI / Anthropic / Gemini 兼容）。

Roadmap⑥ 保真度 "给我的真是这个模型吗？"

固定请求集与官方 API 对拍（K2 Vendor Verifier 方法），检测偷换模型、过度量化、截断上下文。

网关排行榜

默认按 30 天稳定性排序 · 点击表头切换排序 · 不做黑箱总分，按你关心的列排

网关 直连延迟 ↕ 稳定性 30天 ↓ TTFT p50 ↕ 吞吐 tok/s ↕ 价格指数 ↕ 模型数 ↕ TTFT 趋势(30天)

价格对比

单位 USD / 1M tokens（输入 / 输出）· 括号内为相对官方价的倍率 · 官方价来源 litellm 开放价格库

价格指数 = 该网关所有可比模型倍率的几何平均。<1.00 比官方便宜，>1.00 比官方贵。
